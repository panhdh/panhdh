# 月底生存記

無外部依賴的中英文 H5 經營小遊戲（Make Rent / 月底生存記）。手機與桌面瀏覽器皆可使用。

右上角可切換 English / 繁體中文，並記住語言偏好。首次開啟依瀏覽器語言選擇；中文瀏覽器使用繁體中文，其他語言使用英文。切換語言不會重置進度，舊版存檔的數值進度會保留。

每天選一個行動，20 天結束時存款達到 $6,000 即過關。打工賺取固定報酬、進修提升接案收入、休息恢復體力；每日和每五日的支出會自動扣除。遊戲內含完整規則說明。

## 本機執行

在儲存庫目錄執行 `python3 -m http.server 8000 --directory dist`，用瀏覽器開啟遊戲。遊戲不需後端、金鑰或套件安裝。進度儲存在瀏覽器 localStorage；清除網站資料會移除存檔。

## itch.io 上傳

將 `dist/index.html` 放在 ZIP 根目錄。新增專案，Kind of project 選 HTML，並上傳 ZIP；勾選在瀏覽器執行。建議寬度 700、高度 900，開啟全螢幕與手機支援。先設為 Draft，測試桌面與手機操作後再發布。
